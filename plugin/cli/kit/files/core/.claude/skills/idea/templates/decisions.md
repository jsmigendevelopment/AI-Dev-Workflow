# Decisions

Record each decision the moment it's made.

- **During the kickoff** (one session, before the build loop): add a row to the table below.
- **After the kickoff,** a decision is its own file, `docs/decisions/<issue>-<n>.md`: `<issue>` is the issue it was made for, `<n>` counts from 1 within it. Never add a row to the table then: parallel pull requests would pick the same number and clash. The file starts with `# Decision <id>`, then one line each for **Date**, **Decision**, **Options considered**, **Why** and **Originator** (`person`, `default` or `AI pick, not reviewed`). Cite it as `decision <issue>-<n>`; table rows stay `decision <n>`.
- Never delete a row or a file. If a decision changes, write a new one that says `Replaces decision <id>`, and leave the old one as it is.

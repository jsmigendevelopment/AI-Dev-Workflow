# Decision 321-1

- **Date:** 2026-11-27
- **Decision:** The common-word list for kit lessons (#321) is SCOWL size 10 (`english-words-10.json` from the npm package `wordlist-english` 1.2.1, 3,939 words of letters only), copied into `cli/src/lesson-words.mjs` with SCOWL's notice. No runtime package. Its licence is SCOWL's permissive notice (copy, modify and sell with the notice kept); its size-10 source, Moby Words II, is public domain.
- **Options considered:** `google-10000-english` (licence of the underlying data unclear); SCOWL size 10 plus 20 (about 10,700 words, more rare words and so more room for a private detail); SCOWL size 10; a hand-written list
- **Why:** A permissive, documented licence, and the smallest list that still writes plain sentences. A lesson that needs a rarer word uses `[detail]`, which suits an allowlist built for privacy. The kit glossary sits next to it, and every manifest component name is allowed too.
- **Originator:** AI pick, not reviewed

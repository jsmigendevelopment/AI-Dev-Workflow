# Decision 595-1

- **Date:** 2026-11-28
- **Decision:** The Dependabot gate clips each file name in its "changes more than existing manifests and lockfiles" refusal to 200 characters, with `...` after a clipped one (#595, follow-up to #585). (1) **One clip:** `dependabot-bump.mjs` uses the `clip` that `dependabot-go.mjs` already has (now exported), so every quoted value in the gate shares one cap. (2) **Only the message:** the filter that decides which files are "other" is untouched, so the refuse/pass decision, the exit codes and every other message are the same. A name of 200 characters or fewer reads exactly as before, status in parentheses included. (3) **Not JSON-quoted:** unlike `quoted()` for go.mod lines, the names stay unquoted, so the short reason does not change by a character. (4) **Tests:** `AC-595-1` (3000-character paths, added, removed, renamed and modified, one and two names, and the 201-character edge) and `AC-595-2` (short names and an exactly 200-character name read as before) in `cli/test/dependabot-bump.test.mjs`. Proved by running the old and new `dependabotBump` side by side on 74,245 generated file lists (names of 1 to 3000 characters, with many at 199 to 201, every status, manifests, lockfiles, Go files, skipped folders, agent folders): same pass or refuse every time, same message whenever every name was 200 characters or fewer.
- **Options considered:** Clip the whole reason to a length (would cut `ONLY` and the status of later files). Cap how many files are named, with "and N more" (changes the message for short lists too, which AC-595-2 forbids). JSON-quote the names (changes the short reason).
- **Why:** A 3000-character path gave a 3144-character reason, and the reason is posted in a comment. #585 clipped the other quoted values and missed this one.
- **Not changed:** the per-file refusal further down (`Dependabot's #n: <file> <why>.`) still prints the file's name whole, as do the branch name and the commit lines. Each is a different message, and the issue's fence is this one refusal. A file name there must already be a `package.json`, a lockfile or a Go file of a long path. Left for a new issue if wanted.
- **Originator:** AI pick, not reviewed (Full automation). The issue gives the rule. The picks are: reuse `clip` rather than a second helper; no quoting; the test cases.

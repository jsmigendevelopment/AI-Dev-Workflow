# Decision 319-1

- **Date:** 2026-11-27
- **Decision:** The TanStack Start pack keeps `lefthook`, and `knip.jsonc` names it in `ignoreDependencies` with a comment that says why. lefthook is really used: `lefthook.yml` holds the pre-commit hook (Prettier and ESLint on staged files), and `pnpm-workspace.yaml` lets its install script run so `pnpm install` installs that hook. Knip's lefthook plugin counts the package as used only when CI is set or it finds the installed hook in `.git/hooks`. That hook is missing when `pnpm install` ran before `git init`, in a git worktree (where `.git` is a file), or with `LEFTHOOK=0`, so a fresh copy failed `pnpm knip` there. Only this one name is ignored; every other unused dependency still fails. `cli/test/pack-check-fresh.test.mjs` pins both. When the hook is installed, knip prints a configuration hint, "Remove from ignoreDependencies", and still exits 0; the comment above the entry says why it stays.
- **Options considered:** (1) `ignoreDependencies: ["lefthook"]` with the reason (picked). (2) A `prepare` script, `lefthook install`, so knip sees a real use in `package.json`: `pnpm install` then fails outside a git repo, before the person runs `git init`, and installs hooks in CI. A separate `hooks` script would show knip the same use without that failure, but it adds a command nobody is told to run, outside this issue's fence. (3) Remove lefthook and `lefthook.yml`: drops the pre-commit format and lint the pack README and the `stack-tanstack-start` skill promise, the hook that formats a file like `save-fails.test.ts` before it is committed in an app.
- **Why:** The smallest change that tells knip the truth, inside the issue's Modules line, with no check weakened for any other package.
- **Formatter note:** the pack's formatter step is the lefthook pre-commit hook, and it runs only in an app made from the pack. The kit repo commits `stacks/tanstack-start/` with its own git hooks, and the kit's tests read the pack's files without running its Prettier, so the unformatted line in `scripts/cloudflare/save-fails.test.ts` (from #161) reached main. The full fresh-app `pnpm check` is the check that catches it, run by hand on pack changes.
- **Originator:** AI pick, not reviewed (Full automation: the owner, 2026-11-26).

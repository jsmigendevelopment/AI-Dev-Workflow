# Decision 740-1

- **Date:** 2026-11-28
- **Decision:** `config get` (#708, #733) gets a generic second layer, and no allowlist. (1) **Value:** one token with no space, 20 or more characters, holding a letter and a digit, is refused under any name; a value with `://` goes by the URL rule instead. (2) **URL password:** `://user:rest@` where `rest` holds a raw `/` is refused. A port before a path with an `@` (`https://host:8443/a@b`, pinned by AC-733-3) stays readable: it is told apart by a non-empty host and 1 to 5 digits then `/`. A password of 1 to 5 digits then `/` (`mysql://u:123/x@h`) is read as a port and still prints; that is the one gap this rule has. (3) **Value starts:** `bearer `, `basic ` and `ya29.`, lower-cased like the other starts, and a scheme-less `user:pw@host` (a leading `mailto:` is dropped first, so `mailto:me@example.test` still reads). (4) **Names:** the whole words `pw`, `pswd`, `pin`, `totp`, `seed` and `mnemonic` (plural dropped like the others), and any word longer than 4 letters that ends in `pass` (`userpass`, `adminpass`, `mypass`). `passage` and `passive` still read. As a side effect `bypass` and `compass` are refused too; over-refusing is the safe side.
- **Options considered:** The issue's first pick, an allowlist of template keys, was dropped: it would have broken 13 existing tests that read keys not in the template, and the kit never rewrites a test to fit. A strict entropy test on values (more accurate, but needs a threshold nobody can defend). Refusing every long value (hides model ids and dates; the letters-and-digits rule keeps `Cloudflare Workers` and plain words).
- **Why:** A denylist always misses a format. One generic rule catches unknown key formats without a list. Over-refusing costs one "read the file yourself"; printing costs a leaked key. A generated set of 400,000 names and 400,000 values found none that the old lists refused and the new code lets through.
- **Originator:** AI pick, not reviewed (Full automation). The coordinator's scope-change comment on #740 set the four items; the exact rules, the port exception and the `mailto:` exception are the builder's.

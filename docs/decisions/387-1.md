# Decision 387-1

- **Date:** 2026-11-28
- **Decision:** The code scan reads only comments and string literals, with the same `badMentions` as the Markdown scan. It leaves out code, regex literals, JSX text and strings with no space (names, keys, paths, flags). In code text a lowercase `ci` is the `docs/stack.md` key or a file name, so only `ci = "actions"` and `ci = "local"` keep it; `file(s)` opens no clause. It skips `*.test.*` files, `evals/test/`, `evals/scenarios/ci-never-starts/fixture.mjs`, and the two eval graders whose strings name the workflow writes and waits that fail a run (`ci-never-starts` and `show-it-early` `checks.mjs`). The Access token's Cloudflare names (`${worker} CI`, `CI service token`) join the named exceptions, since renaming them would lose the existing token.
- **Options considered:** run the Markdown scan over whole code files; skip every kit script that detects workflows; read comments and strings only, and reword what still fails
- **Why:** Whole files gave hundreds of hits on identifiers and regexes. Skipping the detectors would leave their messages unchecked. Reading comments and strings keeps the clause rule, and the rewords are small. Two preflight warnings lost a comma so `ci = "local"` sits in the same clause, matching doctor's wording; their two pinned strings in `no-actions-warnings.test.mjs` change with them, at the same strength.

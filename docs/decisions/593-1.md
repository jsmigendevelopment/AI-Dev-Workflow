# Decision 593-1

- **Date:** 2026-11-28
- **Decision:** Every guide that a copy in `build/references` links to is copied next to it (#593). (1) `scripts/sync-copies.mjs` adds `code-style-go.md`, `environments.md` and `evidence.md` to the guides it copies into `.agents/skills/build/references`, so the links in `code-style.md`, `app-conventions.md`, `app-conventions-go.md` and `testing.md` all resolve. The first of the three is the one the issue names; the other two were found by the test (`app-conventions.md` and `app-conventions-go.md` link `environments.md`, `testing.md` links `evidence.md`), and the issue's AC-1 fails on `app-conventions.md` without `environments.md`. (2) `.gitattributes` marks the three copies `linguist-generated`, as it does for every copy. (3) `cli/test/build-references-links.test.mjs` follows every relative link in every `build/references/*.md` (and in the `.claude/skills` mirror), outside code, and fails on a missing target; it names the copy and the target. (4) The copy of `environments.md` is read by the Full-branch and approval scans, which the guide never was: three steps got an On Full branch or a new wording in the master (the test and preview protection row, the heading of section 11 and its last bullet), and the production row gets an entry in `approval-scan.mjs`'s allowed list, like the master's, because it is on the always-stop list. (5) Point 7 of `533-1.md` said the Go guide is not copied; it now says it is.
- **Options considered:** name the `guide/` path in the pointer line (a path that exists in the kit but not in an installed app, so the link stays dead where an agent reads the copy; and it fixes only one of the three dead links); copy the three guides (chosen: the link then works wherever the copy goes, and the folder already holds the other guides); drop the three links (loses the pointer to the Go style and the environments guide).
- **Why:** An agent that reads only the copy follows a link, and a link to a guide that is not there costs it a failed read. Copying costs three files and no new rule. The test checks the whole folder, so a fourth dead link fails the day a guide gains one. No `build` References row is added (out of scope in the issue).
- **Originator:** AI pick, not reviewed (Full automation). Copying `environments.md` and `evidence.md` as well as `code-style-go.md` is the builder's pick.

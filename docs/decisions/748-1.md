# Decision 748-1

- **Date:** 2026-11-28
- **Decision:** How `insights.mjs land` holds records for a batch (#748). (1) `land` without `--now` lands only when 12 or more record files are unlanded, or the oldest is 90 minutes old or more. Otherwise it prints one `held: <n> records, oldest <m> min; lands at 12 records, 90 min or with --now` line on stdout, opens or extends nothing, calls no API, stages nothing and exits 0. (2) A record's age is its own `at` field read against the clock (`ONRAILS_NOW` in tests), not the file's modified time, which a checkout or a copy resets. (3) A held record is never moved or deleted: it stays in the checkout's `docs/insights/`, so `has-records` (which reads that folder) and the next `harvest` and `land` see it. `land --verify <pr>` reads the pull request's own branch and never the held files, so it is unchanged. (4) `land` takes only `--repo <value>`, `--verify <pr>` and `--now`, each at most once, and `--verify` never with `--now`. Anything else exits 2 with the usage line, checked in `insights.mjs` before the checkout is looked up, so no git command runs and no API is called. (5) `afk` at its hard stop and `back` at the end of a retro run `land --now`, so the last records of a run don't wait on a batch. (6) `flow.mjs` counts merged pull requests titled `Insights records...` and prints `records-only pull requests: <n> of <m> merges` when there is at least one. (7) The land tests' `run` helper adds `--now` to a bare `land`, so the existing tests, which check what `land` does when it lands, keep their assertions; the hold tests pass `raw`.
- **Options considered:** For the trigger: a count or an age alone (a quiet run would hold its last records for ever, or a busy one would still land every sweep); both, picked. For the age: file modified time (reset by a copy or a checkout, hard to test); the record's `at`, picked. For the held line: stderr (a caller that reads stdout for the pull request number would see nothing and no reason); stdout, picked. For a bare `land` in the old tests: edit each call to add `--now` (twelve edits to existing tests); the helper adds it, picked.
- **Why:** 59 of 119 merges in the retro run were records-only pull requests, and each moved main under every open code pull request, so 48 of 60 code pull requests ran the full local gate twice. Records need to land, not land every sweep.
- **Originator:** AI pick, not reviewed (Full automation: the owner, 2026-11-28). The thresholds 12 records and 90 minutes are the issue's own AI pick.

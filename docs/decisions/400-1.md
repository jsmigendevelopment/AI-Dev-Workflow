# Decision 400-1

- **Date:** 2026-11-27
- **Decision:** `check-issue-size.mjs` closes five gaps from the round 4 review of #391. (1) An exception whose reason names an issue (`#12`), or says it is split ("split into ...", "split in two", "already split", "was split", or only "split"), fails as both an exception and a split, unless a "no", "not", "never", "can't", "cannot", "won't", "don't", "unable", "without", "hard" or "too" comes before the split ("can't be split into parts", "too risky to split up"). (2) A later part of the value fails as a second estimate when one word sits between its number and "lines" or "loc" ("+600 test lines"), or when "test" or "tests" sits next to a number ("tests: 600", "600 in tests"). A path ("test/12-x.ts", "x.test.mjs") or an ID ("AC-12-1 tests") isn't one. (3) A reason fails as a placeholder when it is "nope", "no reason", "no reason given", "not needed", "not applicable" or "no need", or starts with "none", "tbd", "todo" or "n/a" ("none yet", "TBD later"), except "none of ...". (4) The guard for a size the reader skips needs the unit right after the number, with at most one of "changed", "total", "new", "more", "added" or "test" between, so "font size: 16px, line-height: 24px" passes; "about 300 lines changed" reads as 300. (5) On stdin, a split parent with no `labels` exits 2, and the exit 2 message names `labels`. (#400)
- **Options considered:** for (1), fail any reason with "split" in it (refuses "no way to split a rename", a real reason the tests keep), only a reason that names an issue (misses "split into child issues"), or the split phrases above unless a negation comes first. For (2), one word before the unit, or any words (refuses file lists). For (3), the exact phrases only, or a starting word too. For (4), the review's regex as given, or with a short list of words allowed between the number and the unit, so "Size - 1,500 total lines" stays caught. For (5), exit 2 for any issue with no labels (breaks older input that splits nothing), or only for a split parent.
- **Why:** Each choice fails the misuse the review found and keeps every real wording the tests and this repo's own issues use. No shape main fails now passes: a probe of 45 shapes found none that got looser, and all 28 real `Size:` issues in this repo read the same or better (#400's own body no longer trips the guard). The plan check imports this reader, so a step cell gets the same stricter rules.

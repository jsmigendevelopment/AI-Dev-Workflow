# Decision 187-1

- **Date:** 2026-11-27
- **Decision:** How #187 opens the paste window on Windows. From PowerShell: `Push-Location -LiteralPath '<app folder>'; [Environment]::CurrentDirectory = (Get-Location -PSProvider FileSystem).ProviderPath; Start-Process cmd ...; Pop-Location`, so the folder never goes through `-WorkingDirectory`, which can read `[` and `]` as a wildcard in Windows PowerShell. From Git Bash: `(cd '<app folder>' && MSYS_NO_PATHCONV=1 cmd.exe /c start "" cmd /k pnpm connect <provider>)`, so the folder never reaches cmd. "No agent step after the press" counts a sentence with a `**` button or one that starts with an action word.
- **Options considered:** Keep `-WorkingDirectory` and escape `[`/`]` with `[WildcardPattern]::Escape` (breaks where the parameter is literal); keep `-WorkingDirectory` unchanged (a folder with brackets may fail); Push-Location -LiteralPath and the current folder
- **Why:** `-LiteralPath` is literal in every PowerShell version, and Start-Process starts from the process's current directory in Windows PowerShell 5.1 (only PowerShell 7 uses the pushed location), so the line sets `[Environment]::CurrentDirectory` to the pushed folder's file-system path first (fix round 1 on #298). Not run on real Windows (out of scope).

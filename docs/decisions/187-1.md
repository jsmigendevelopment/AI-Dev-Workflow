# Decision 187-1

- **Date:** 2026-11-27
- **Decision:** How #187 opens the paste window on Windows. From PowerShell: `Push-Location -LiteralPath '<app folder>'; Start-Process cmd ...; Pop-Location`, so the folder never goes through `-WorkingDirectory`, which can read `[` and `]` as a wildcard in Windows PowerShell. From Git Bash: `(cd '<app folder>' && MSYS_NO_PATHCONV=1 cmd.exe /c start "" cmd /k pnpm connect <provider>)`, so the folder never reaches cmd. "No agent step after the press" counts a sentence with a `**` button or one that starts with an action word.
- **Options considered:** Keep `-WorkingDirectory` and escape `[`/`]` with `[WildcardPattern]::Escape` (breaks where the parameter is literal); keep `-WorkingDirectory` unchanged (a folder with brackets may fail); Push-Location -LiteralPath and the current folder
- **Why:** `-LiteralPath` is literal in every PowerShell version, and Start-Process starts from the current location. Not run on real Windows (out of scope).

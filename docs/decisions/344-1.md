# Decision 344-1

- **Date:** 2026-11-27
- **Decision:** The tech grill decides the backend and the host before the framework. No backend (a static or content site): TanStack Start alone, Next.js the alternative. A backend on Cloudflare Workers: TypeScript (Start server functions or a Workers API, with D1). A backend not on Workers: a Go backend with a TypeScript web frontend that calls it.
- **Options considered:** TypeScript backends everywhere (the old default); Go for every backend, Workers included; the rule above
- **Why:** The owner (2026-11-27, in #279): "if an app needs a backend, unless it's like a static content website or something like that is like, using TanStack Start or Next.js. But if it needs a backend, we shouldn't recommend TypeScript backends like we are right now. We should recommend Go." Refining it (2026-11-27, #279's comment): "unless it's running on Cloudflare workers, right?"
- **Originator:** person (the owner, 2026-11-27, in #279), with the wording of the grill questions an AI pick, not reviewed

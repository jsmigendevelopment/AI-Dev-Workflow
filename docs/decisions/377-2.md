# Decision 377-2

- **Date:** 2026-11-27
- **Decision:** What `pr-size.mjs` leaves out: lockfiles (the list `pr-rules.mjs` already had), files main's committed `.gitattributes` mark `linguist-generated` (the kit's synced copies, and each pack's list in its own `.gitattributes`), and test fixtures, meaning any path inside a `fixtures`, `fixture`, `__fixtures__`, `testdata` or `__snapshots__` folder. A rename is left out only when both its names are. A local run (`--base <ref>`) counts the committed branch against `<ref>`, and has no label, so it can't pass on an exception. A `Size exception:` line whose reason is the template's own `<reason>` doesn't count.
- **Options considered:** a fixed list of fixture files per pack; the `linguist-generated` attribute for fixtures too; folder names, as above
- **Why:** Folder names need nothing set up in an app, and match how test tools name fixtures. Each pack already lists its generated files in its `.gitattributes`, so reading that keeps one list per pack. The exception lives on the pull request, where the gate and the reviewer see it.

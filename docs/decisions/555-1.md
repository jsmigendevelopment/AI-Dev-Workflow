- **Why:** The repo's enforced rule wins over the issue's literal "in place": the research standard makes `claims.csv` append-only and the checker fails an edit to an existing row. Appended rows give the same pointer from c3 and c4 to c69. `git status --porcelain` is one command, changes nothing and also catches a regenerated file that is staged but not committed.

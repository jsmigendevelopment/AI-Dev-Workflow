# Decision 380-2

- **Date:** 2026-11-27
- **Decision:** `usage_before` and `usage_after` are text, written as the tool shows the reading (for example `41%`), or `unknown`. `usage_from` names where it was read, or where the run looked when there was nothing to read. No pattern is enforced on the reading.
- **Options considered:** a number from 0 to 100 (it only fits a plan percentage, and pushes a run to turn another reading into one, which is an estimate); a cost in dollars (subscription plans show no per-run cost, and a session-wide figure isn't this run's); text as shown, with its source, as above.
- **Why:** #380 says never estimate a number the tool didn't report. Tools show usage in different forms, and many cloud sessions show none to the agent. Text as shown, plus where it came from, records exactly what was seen. The weekly report (#381) decides how to read it.
- **Originator:** AI pick, not reviewed

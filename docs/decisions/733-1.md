# Decision 733-1

- **Date:** 2026-11-28
- **Decision:** `config get` (#708) refuses more, and refuses nothing less. (1) **Names:** the whole words `cred`, `pwd`, `pass`, `passcode`, `jwt`, `cookie`, `otp`, `hmac`, `salt`, `cert` and `pem`, with the plural dropped (`s` or `es`, so `creds` and `passes` count); the pairs `auth header`, `database url` and `connection string` as two words in a row; and the glued parts `dbpass`, `smtppass`, `passcode`, `pwd`, `cookie`, `hmac`, `licensekey`, `authheader`, `databaseurl` and `connectionstring`. Short words stay whole-word only, so `passage`, `certain`, `saltire`, `cookbook` and `opt` still read. (2) **Values:** the prefixes `sk_test_`, `pk_live_`, `pk_test_`, `rk_live_`, `rk_test_`, `whsec_`, `ghu_`, `ghs_`, `ghr_`, `xapp-`, `glpat-` and `npm_` (lower-cased like the old ones); case-sensitive `ASIA` plus a letter or digit and `AIza` at the start (so the word `Asia` is not caught); anywhere in the value, a JWT shape and `hooks.slack.com/services/`; and a URL with `user:password@`. (3) **URL with a password:** refused, not masked (the issue's pick: simpler and safer; masking needs a parser and one slip prints the password). (4) **Reader:** inside a `"""` string a backslash escapes the next character, so `\"""` does not close it; a `'''` string has no escapes. The same check runs on the opening line. (5) **Files:** the lists and the two checks moved to `cli/src/config-secrets.mjs` so `config.mjs` stays under 300 lines. The tests for the new lists are in `cli/test/config-get-secrets.test.mjs`, because `config-get.test.mjs` would pass 300 lines.
- **Options considered:** Mask the password in a URL and print the rest (a parser, and a mistake leaks it). Refuse `pass` and `cert` anywhere inside a word (hits `passage`, `certain`, `bypass`). Match `ASIA` and `AIza` without case (refuses the word `Asia`, which the template's own wording could use). Refuse every URL (hides `https://example.com`).
- **Why:** Agents run this command, so a printed secret can land in a transcript. Over-refusing costs one "read the file yourself"; printing costs a leaked key. A fuzz of about 11,000 names and values against the old lists found none that the new lists let through.
- **Originator:** AI pick, not reviewed (Full automation). The word, phrase and prefix lists, the case rules, the refuse-not-mask pick and the second test file are the builder's.

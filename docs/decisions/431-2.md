# Decision 431-2

- **Date:** 2026-11-28
- **Decision:** How the weekly report reads the new fields, and the two small items from the comment on #431. A run crossed its window's reset when `usage_resets_before` or `usage_resets_after` is a time inside the run: not after the run's end (`ended`, else the record's `at`), and, when the record has a parseable `started`, after it. It also did when both readings name a window, neither is `unknown`, and the two differ. A crossed run's usage is `unknown`, so its pull request's is too (the usage per merge already makes any run without a usable reading `unknown`). A missing or `unknown` window or reset says nothing, so a record from before #431 is read as it was. The "With a reading" column counts the runs whose usage is usable, so it drops by a crossed run. Escalations: a build with an unknown model or effort can't be told from a retry or from an escalation, so the row before it, and its own row, print `fixed it` as `unknown`; a build with known model and effort after a retry on the same model and effort stays inside the escalation's row (a test now holds it).
- **Options considered:** for a crossing: the reset time against the run only (misses a run whose tool showed the window at the end only, and two windows); the reset times of the two readings differing (a reading's time can shift by seconds, so a false `unknown` on a quiet run); the run containing a reset time, or two windows, as above. For the unknown rows: say in decision 381-2 that equal recorded values count as a retry (then two builds the report can't tell apart look like one, and `yes` would stand on a guess); `unknown` for the earlier row only (leaves the row after an unknown build reading a window that may belong to the retry); `unknown` for any row beside an unknown build, as above.
- **Why:** The owner's rule: never estimate a number the records don't hold. A run that crossed a reset reads low, and a guess at where one build's row ends is the same kind of guess. `unknown` shows which readings to start recording.

# Decision 410-1

- **Date:** 2026-11-28
- **Decision:** What `lesson check --project` takes out of the deny set, and what it now never opens (#410, on decisions 322-1, 385-1 and 392-2).
  - **The pack's own env names:** a variable name in the project's `.env.example` that a stack pack in the CLI's bundled kit also ships in its own `.env.example` gives no term (`SECURITY_CONTACT`, `CLERK_SECRET_KEY`, `TURNSTILE_SITE_KEY`). A name of the project's own still gives its whole name, and its spaced and hyphenated forms, as before. The names come from every `.env.example` of every pack in the bundled kit, read from the CLI's own files, never the network, and compared exactly (same letters, same case).
  - **The pack's own hosts:** a host that appears in any text file of any bundled pack gives no term, even from a file the project has edited, as `accounts.dev` no longer gives "accounts dev". The match is the whole host, lower-cased. A deeper or longer host (`my.accounts.dev`, `accounts.dev.io`) is still the project's, and a file the project has edited and that holds a host of its own still gives it.
  - **`times out of`:** a number followed by `times` is a count when `times` ends the phrase, or when `times out of` is followed by a number: a digit, a number word (`one` to `twelve`, `twenty`, `thirty`, `forty`, `fifty`, `hundred`) or `the last`. `issue 41 times out of memory`, `... out of the blue` and `... out of.` are refused as an issue number. This replaces the `times out of` bullet of decision 392-1 and the count bullet of 385-1.
  - **More env files never opened:** a path is never opened when any part of it, a folder too, is named `.env`, `.envrc` or either followed by `.`, `_` or `-` and anything (`.env_local`, `.env.d`, `.envrc.d`), or ends in `.env` or `.envrc` (`prod.env`), in any case (`.ENV`, `.Envrc`). `.env.example` is still read, only as the last part, spelled exactly so. For a link, only the part of the real path under the project counts, so a project kept inside a folder such as `~/prod.env/` still reads.
  - **Also in this change:** the plural forms of the kit-word check have a test for each form; the privacy test file ends with a newline; `cli/CLI.md` says a read stops at 1 MB and one byte.
- **Options considered:**
  - Env names: skip a name only when the project installed that pack (needs a read of the project's `.onrails.json`, and a project made before packs were recorded loses it), or skip a name of any bundled pack. A pack's name is the kit's own public text, so the second is as safe and simpler.
  - Hosts: skip only files that match the pack's files by hash (the issue says an edited file must work too), skip the whole name label of a pack host (`accounts` would then leak a project's `accounts.example.io`), or skip the exact full host. The last is the narrowest.
  - `times out of`: refuse every `times out of`, or count only when a number follows `of` as the review of #423 tested.
  - Env files: add only the five names the issue lists, or judge every part of a path with one pattern. The second also refuses `.env.d/` files that no list named, and costs nothing: no kit or pack file has such a name.
- **Why:** The pack's names and hosts are the kit's own, so refusing them only blocks ordinary lessons (`security contact`). Everything that is the project's own is still refused: its names, its hosts, its numbers. The env file list stays wider, never narrower, so rule 9 holds for the names projects use on case-blind file systems too.

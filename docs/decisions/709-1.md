# Decision 709-1

- **Date:** 2026-11-28
- **Decision:** `npx onrails map [dir]` (`cli/src/map.mjs`) writes `docs/map.generated.md` with these rules. (1) **Modules:** the folders of `src/modules/`; with no `src/modules/`, the folders of `src/`. Code in `src/` outside any module is `(root)`; a folder with no code file is not a row. (2) **Lines of code** are the non-blank lines of the counted files (`.ts`, `.tsx`, `.js`, `.jsx`, `.mjs`, `.cjs`). (3) **Imports** are read from the text with comments blanked and every quoted string replaced by its number, so an import inside a comment or a string is never an edge. Followed: `import`, `export ... from`, `require("x")` and `import("x")` with a plain string, by a relative path or an `@/` path (`src/`). A package, a path outside `src/`, a template string and any other alias are not followed. (4) **Cycles** are found among modules only: `(root)` is a catch-all (shared helpers and routes import modules, and modules import helpers), so a loop through it says nothing about the modules. Each group of modules that reach each other prints as one shortest loop, and `(linked loops: ...)` names every module when the group is bigger than that loop. (5) **Sideways imports** are checked only when `src/modules/` exists, since only those folders are feature modules; otherwise the file says "Not checked". (6) **Same bytes on a second run:** names sorted by code point with `(root)` last, `\n` line ends, no dates, and only paths relative to `src/`. (7) **Skipped:** `node_modules`, `dist`, `build`, `coverage`, hidden folders, `.gen.` files and links (a link is never followed, so a loop or a path outside the app cannot be read). (8) **No `src/`:** the file says so and lists nothing. A missing folder exits 1.
- **Options considered:** Count every line, as `wc -l` does (easier to check by hand, but "lines of code" then includes blank lines). Put `(root)` in the cycle search (flags nearly every app, since a route imports a module and the module imports a helper). Read `tsconfig` paths for other aliases (needs a JSON-with-comments parser or a new dependency; the issue names only `@/`). A real JS parser for the scan (a new dependency, which the issue rules out).
- **Why:** The issue asks for a built-in scan with no new dependency, and for a file that is the same on a second run. A text scan with the comment and string guard is exact enough for module-level edges, and its limits are listed in `cli/CLI.md`.
- **Originator:** AI pick, not reviewed (Full automation). The lines-of-code meaning, `(root)` staying out of cycles, "Not checked" for sideways imports in the `src/` layout and the skipped folder names are the builder's picks.

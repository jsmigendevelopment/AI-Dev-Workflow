# Decision 340-1

- **Date:** 2026-11-27
- **Decision:** The Go pack (#279) builds on these picks from the dossier [Go API platform](../../research/go-api-platform.md). (1) The `stack` grill asks one question with six signs that an app outgrows Workers: more than 5 minutes of CPU for one request or queued job (15 minutes for an hourly or rarer cron), more than 128 MB in memory, a program outside JavaScript, TypeScript, Python and Rust, uploads over 100 MB, a server that never stops, or a database over 10 GB. Any "yes" means a Go backend off Workers. The fresh-session fact-check dropped a seventh sign, more than 6 calls waiting at once, because extra calls wait in line rather than fail. (2) The Go service runs on Google Cloud Run, deployed with `gcloud run deploy --source .` on request-based billing and previewed with `--no-traffic --tag`, setting every environment variable on every deploy; Fly.io is the runner-up. (3) Its database is Postgres on Neon through pgx, with goose migrations and sqlc queries; never D1 over its HTTP API. (4) It checks Clerk sign-in with Clerk's Go SDK middleware, using `RequireHeaderAuthorization` and `AuthorizedPartyMatches`; golang-jwt v5 with keyfunc v3 is the fallback. (#340)
- **Options considered:** hosts: Cloudflare Containers, Fly.io, Railway, Google Cloud Run, a small VPS; databases: D1 over HTTP, Neon, Supabase, SQLite on a volume; migrations: goose, golang-migrate, Atlas; queries: sqlc, pgx alone, sqlx, GORM, Bun; sign-in: Clerk's Go SDK, golang-jwt with keyfunc, jwx
- **Why:** Cloud Run costs nothing at idle and at small load once a Paid billing account exists, on request-based billing (instance-based billing bills idle time even with min instances 0), bills only usage above its Free Tier, builds Go with no Dockerfile, and previews each change as a tagged revision of the same service from the CLI, which fits the kit's no-Actions rule. Fly.io is also free for a small app with a card and can preview from the CLI, but each preview is an extra app against a 3-Machine Free plan, and a month over $5 is billed in full. Cloudflare calls D1's HTTP API best for admin use, under a limit of 1,200 requests per five minutes per user or token. Neon is free, scales to zero and branches per preview from its CLI; it runs only on AWS, so pick a region close to Cloud Run's. Clerk's SDK caches keys for an hour and, once configured, checks `azp` and clock skew for the app; `AuthorizedPartyMatches` lets a token with an empty `azp` through, which the Go pack's sign-in issue must decide on. Confidence: high for the Workers limits and against D1 over HTTP, medium for the rest. Re-check by 2027-02-27.

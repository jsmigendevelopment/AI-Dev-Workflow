# Decision 164-1

- **Date:** 2026-11-27
- **Decision:** What the agent-file guard counts as a deleted test (#164). A test is a file with `.test.` or `.spec.` in its name, or any file under a folder named `test`, `tests`, `__tests__`, `e2e` or `__snapshots__`, or one ending in `-snapshots`, in any case. Status `removed` on a test, or `renamed` from a test name to a non-test name, is protected and named `<path> (a deleted test)`. A rename between test names, an add or an edit isn't. `deletedTests()` reads the status the file list already has, so `gate`, `--pr` and test mode all see it with no new API call.
- **Options considered:** protect every test edit; protect any rename of a test; detect deletions from the patch.
- **Why:** Flagging edits would gate every build; the issue's own list of what counts is followed as written.
- **Originator:** AI pick, not reviewed (Full automation: the owner, 2026-11-26).

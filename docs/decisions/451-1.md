# Decision 451-1

- **Date:** 2026-11-28
- **Decision:** The five follow-ups of the #446 review ship together, and each one only tightens the scan. (1) A merge ban carries past a colon into the next sentence, so "Don't merge: CI hasn't finished." fails. (2) The scan reads YAML plain values, `|` and `>` blocks and a plain value's wrapped lines, as well as comments and quoted strings; decision 387-1 no longer lists them as a gap. Flow collections (`[a b]`, `{a: b}`), tags (`!!str`) and anchors (`&a`) are still read only through their quoted strings, a named gap. A line ending in CRLF, or holding a stray `\r` or U+2028, is read like an LF line and never crashes the scan. (3) The three test titles that named CI or the workflows as the actor are reworded, title text only: "lets the smoke test through ...", "the mode it names", "when the deploy files read TEST_X or X". (4) A lowercase `ci` in code text is swapped for "key" only when it is backticked, joined to a hyphen (`ci-mode.ts`, `preflight-ci.mjs`) or the key's quoted value (`ci = "…"`, `ci = "actions-later"`); any other lowercase `ci` ("// wait for ci", "// wait for ci = done") is read, and `ci = "actions"` and `ci = "local"` stay. (5) The 190-character comment line is wrapped and `codeText` is no longer exported.
- **Options considered:** for (2), name the gap in 387-1, or read plain and block values; for (4), keep the swap, narrow it to the three forms the repo uses, or drop it and reword the few names it covers
- **Why:** The scan enforces the owner's "No GitHub Actions" rule, so a slip it misses costs more than a reworded comment. Reading YAML values is about 40 lines and passes over every YAML file in the fence with no new hit. The narrowed swap is exactly what an unswapped run showed: file names, the `docs/stack.md` key and its quoted values, and nothing else: the whole-repo scan gives the same hits in the fenced code files before and after the narrowing.
- **Not done here:** `cli/test/ci-local-secrets.test.mjs` has the same "the CI it names" comment as the pack's `local-keys.test.ts`. The issue names only the three pack files, so it stays.

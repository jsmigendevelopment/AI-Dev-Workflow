# Decision 385-1

- **Date:** 2026-11-27
- **Decision:** How `lesson check --project` reads joined names and issue numbers (#385), on top of decision 322-1. A term kept whole (an `.env.example` variable name, a full host) now also gives its parts joined by a space and by a hyphen, but still not its parts alone: `RIVER_SIGNAL_TOKEN` gives `river-signal-token` and `river signal token`, never `river` or `signal`. A one-word term of letters and digits (`brightpaper`) also matches a run of two or more lesson words that spells it once the spaces and hyphens between them are removed (`bright paper`, `bright-paper`), in either number; a word alone never does, so `paper` still passes. With a project (always, in the CLI, since `--project` defaults to the current repo), `issue <n>`, `PR <n>` and `pull request <n>`, with an optional `number` or `no` before the number, are refused for any number as `field: contains a project term (issue number)`. `#<n>` was already refused by #321's sentence rules. The number is never printed.
- **Options considered:** Joined names: split a joined name into dictionary words when the set is built (needs a word list, and a name can split more than one way), or join the lesson's words when it is checked. Which joined terms: only names from the remote and package files, or every one-word term (the same rule for every source, and one more refused run in a realistic app: none). Env names: keep them whole as 322-1 says, split them into parts (blocks `key`, `secret`, `token`), or keep them whole plus their spaced form. Issue numbers: refuse them only when the number shows up in the project's files (misses an issue the docs never name), or for any number when a project is checked. Where the issue check runs: inside the term matcher, or next to it in `lesson-check.mjs` (it needs no deny set, so a project with no terms still refuses it). `#<n>`: refuse it twice, or leave it to #321's rule.
- **Why:** Privacy first, and the false refusals stay where they were. In a fresh app made with `init` and `add tanstack-start` and its own made-up docs, 2 of 41 clean kit-style lessons were refused before and after (both for `start`, from TanStack Start in the docs), and 8 of 3,939 common words before and after. The one new refusal there is the phrase `security contact`, from the pack's own `SECURITY_CONTACT` in `.env.example`. A kit lesson is about the kit, so a project's issue numbers carry nothing a lesson needs.

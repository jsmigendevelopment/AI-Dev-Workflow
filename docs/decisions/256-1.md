# Decision 256-1

- **Date:** 2026-11-27
- **Decision:** The TanStack Start pack stays on `drizzle-orm` 0.45.4 and `drizzle-kit` 0.31.11 until Drizzle 1.0 is stable on the `latest` tag. Only the Drizzle recipe's note changes: its agent tools need 1.0 rc, and the move is a new issue once 1.0 is stable.
- **Options considered:** (1) Move now to `1.0.0-rc.6` (registry 2026-11-20): unlocks Drizzle's skill and MCP server, but an rc in a starter every new app copies, a second rc in a month (rc.5 2026-10-21), and 1.0 changes the migration folder layout and the relational query API, so the generators, recipes and every app made from the pack follow it. (2) Wait for 1.0 stable (picked): no churn, the pack keeps the `latest` tags (`drizzle-orm` 0.45.4 2026-10-08, `drizzle-kit` 0.31.11 2026-09-21); the cost is no Drizzle agent tools in pack apps. (3) Optional rc lane: keep 0.x pinned and document a per-app opt-in to rc: two lines to support and test, for a convenience gain.
- **Why:** The `dependencies` skill swaps only for a concrete gain. The only gain is the vendor's agent tools, a convenience, not a fix; the risk is migrations and API churn across every app made from the pack while Drizzle still ships release candidates.

# Decision 424-1

- **Date:** 2026-11-28
- **Decision:** How the run-cost follow-ups (#424) close. (1) `validate` refuses `send_back` on any job record whose outcome isn't `fail`, `failed`, `stopped` or `handed-off`, a missing outcome included. A board record (which may leave `outcome` out) can no longer carry one. (2) A line separator (U+2028, U+2029) in a text field is kept, not refused. The line pattern in `parseLine` and in harvest is `[^\r\n]*?`, which stops at a real line break only. `JSON.stringify` never writes a raw line break, so no record line is cut short. Files on disk were never affected. (3) Harvest also counts how many `<!-- onrails-insights ` openers a trusted comment holds and names the comment when more were opened than matched, so a line it can't read is never skipped in silence. (4) `pr-review`, `qa` and `pr-security` say `(quote it if it has spaces)` after `<usage-from>`, as `build` does. `references/insights.md` quotes its example. `pr-security`'s `send_back=review-must` sentence is `pr-review`'s word for word. (5) `qa` step 5 puts `send_back=infra` when the preview or browser wouldn't run, else `send_back=checks`, for an acceptance check, the access test or the error and empty states. (6) Local mode step 3 writes the same `job=size-check` record as `coordinate` step 6.1.1, with `pr=null`.
- **Options considered:** For line separators: refuse U+2028 and U+2029 in every text field (a second rule for each field, and a person's own words, such as a copied quote, would be refused for no harm); escape them in `toLine` (the line would differ from the file's bytes, and the record on disk would still hold the raw character). For the unreadable line: leave harvest as it was (silent skips are what the issue names). For the quote rule: a shell-quoted `usage_from="<usage-from>"` in the command itself (a value with a quote in it would break the command; the words are for the agent).
- **Why:** Keeping the character needs one pattern change and no new refusal, and the exact bytes of every record on main stay valid. Naming an unclosed line costs a count, not a second parser.
- **Originator:** AI pick, not reviewed (Full automation: the owner, 2026-11-26). The ask is the issue's own words, with the choice between the `s` flag and a writer refusal left open.

# Decision 376-1

- **Date:** 2026-11-27
- **Decision:** A step's line estimate goes in a new `Lines` column of the pyramid's steps table, after `Size`. The cell holds the issue's `Size:` value from #375: `about 300 lines`, a range, or `exception: <reason>`. The issue's `Size:` line starts from it. `Size` stays the complexity score. The `idea` template's steps table gets the column, and its skeleton row says `exception: copies the stack pack's starter whole`. (#376)
- **Options considered:** a new column; a second part of the Size cell ("3 · about 300 lines"), which clashes with the reason a big step writes after the `·`; rename `Size` to `Complexity` and use `Size` for lines, which breaks every plan and the issues skill's words
- **Why:** A column keeps the complexity reason and the estimate apart, and one shape for both skills means the issue copies the cell as it is. The template must change with the checker, or a plan written from it fails the check on its first run.

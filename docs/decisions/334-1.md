# Decision 334-1

- **Date:** 2026-11-28
- **Decision:** Every ask through `notify.mjs` writes an `ask` insights record after the ping is decided, from both the CLI and the hook (#334). The wait goes in the existing `waited_minutes` field, not a new `waited` field as the issue's AC-334-4 words it. The answer record keeps the first record's file name in a new optional `answered` field, whose value must match an ask file name (`<hhmm>-ask-<n>-<id>.json`) and which needs `waited_minutes`. The writer counts the wait and copies the first record's rule, level, issue, pr and title unless passed; it refuses a passed `waited_minutes`, a name with no valid ask record, an answer to an answer, and a time before the ask. `validate` now refuses a control character in an ask's `rule` path and `title`, and `notify.mjs` turns those into spaces before writing. A `--rule` that isn't `<path>:<line>` is written as `rule: "missing"` with `rule_ok: false`, and the JSON warns. `rule_ok` is false for an absolute path or one with `..`. `full_should_prevent` is true on Full unless `--always-stop` was passed, for hook records too, and false below Full. Every level writes a record, FYI included, as the issue's "sent, batched, held or recorded" says. `notify.mjs` passes `model_from` because it isn't told the model or effort.
- **Options considered:** for the wait, a new `waited` field (a second name for what `waited_minutes` already holds), or the existing field; for the answer, no stored link (the two records can't be paired later), a free-text link, or a pattern-checked file name; for a bad `--rule`, refusing the record (losing the stop), or `missing` with `rule_ok: false`.
- **Why:** The record format since #329 already has `waited_minutes`, and the code wins over the issue's wording. A pattern-checked `answered` lets #341 pair each wait with its stop, and can't carry a path or a control character. Copying the first record's fields means the agent that acts on an answer needs only the file name. A stop is always written, even with a bad rule, because counting stops matters more than a clean rule. Every record on main still passes the stricter `validate`.
- **Left out:** person-touch records (#336) and summing stops per hour (#341), as the issue's fence says. `notify.mjs` is now 331 lines, over the 300-line warning and under the 500-line stop.

# Decision 329-1

- **Date:** 2026-11-27
- **Decision:** An insights record's file name is `<hhmm>-<kind>-<n>-<id>.json`, where `<n>` is the PR, else the issue, else 0, and `<id>` is 6 random hex characters. (#329)
- **Options considered:** `<hhmm>-<kind>-<n>` with no id, as #281 asked, and hope two writes never meet; a counter suffix (`-1`, `-2`), which two branches both start at 1; a random id
- **Why:** Two branches can write the same kind for the same number in the same minute, and `git merge` then conflicts on an add/add. A counter can't see the other branch. Six hex characters make a clash one in 16 million, and the writer refuses to overwrite (`wx`) in the rare case it happens on one branch.
- **Originator:** AI pick, not reviewed

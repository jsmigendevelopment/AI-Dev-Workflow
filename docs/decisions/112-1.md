# Decision 112-1

- **Date:** 2026-11-27
- **Decision:** The orphan sweep is one script, `coordinate/scripts/orphans.mjs`, that the board render, the coordinator's step 10 and `/back` all use. It reads the sweep's one issue read, which now asks for `comments,body,createdAt` too, so there is no extra read. A handoff record (a `Handoff ·` comment or body, labelled or not, or a `Claimed by` comment) with no `Got it ·` receipt counts once past its "check by" time, or 2 hours after the record when it names none. A claim is stale after 2 hours with no commit and no open pull request on its branch.
- **Options considered:** a second `gh issue list` for claimed and `handoff` issues with their comments; the comments in the one read the sweep already makes (picked: GitHub prices a read by the nodes it asks for, so one read with comments costs less than two); the check left as skill text only, with no script
- **Why:** #112 (follow-ups from the review of #110): a builder dispatched moments ago shouldn't be flagged, step 10 had no comments to check, and a handoff written as a comment never gets the label. A claim waiting on review has no new commits by design, so an open pull request keeps it fresh.

# Decision 322-1

- **Date:** 2026-11-27
- **Decision:** How `lesson check --project` builds and matches the deny set (#322). Each term, and each part of it split on `-`, `.` and `+`, is a term; `_` reads as `-`. Kit words (the glossary and every component name in the CLI's own manifest) leave the set; common words stay. Docs give capitalised words that don't start a sentence (after a lowercase word, a digit or a comma, and not opening a quote, backtick or bracket), plus capitalised words of a level-one title. Domains come from URL hosts and email addresses in tracked files: the full host and its name label (`fernway` in `api.fernway.dev`, `saltmarsh` in `saltmarsh.co.uk`), never reserved names such as `example.com` or `.test`. Git authors whose name ends in `[bot]` are skipped. `.env` and every `.env.*` but `.env.example` are skipped by name before any read; `.env.example` gives whole variable names only. Matching is whole-word (a letter or digit on either side breaks it) and case-blind, across every string field, one error per field, as `field: contains a project term (<kind>)`. The command takes `--project <dir>` (default: the top of the current git repo, else the current folder) in place of #321's `[dir]`, which had no use yet.
- **Options considered:** Split terms into parts, or keep them whole (a repo `pulse-notes` then leaks `pulse`); every heading word as a title word (blocks `what`, `the`), or capitalised title words only; bare domains in code too (catches `this.app` as a host), or URL and email hosts only; split `.env.example` names into parts (blocks `key`, `secret`, `url`), or whole names only
- **Why:** Privacy first: a wrong term fails closed and names its source kind, so the person can see why. The choices that only widen the set (parts, every capitalised name) cost an odd refusal; the ones that narrow it (no bare domains, no sentence-start capitals, no bots, no reserved hosts) stop common words such as `the` or `example` from blocking every lesson. A bare domain in a lesson is refused by #321's one-sentence rule anyway.

# Decision 506-1

- **Date:** 2026-11-28
- **Decision:** Each of the 18 scripts listed in #506 gets the real-path guard #439 gave `pr-size.mjs`, written in the script itself as a small `isMainModule()` that compares `realpathSync(process.argv[1])` with `realpathSync(fileURLToPath(import.meta.url))` and is false when `argv[1]` is missing or names no file. No shared helper. `resolve` is dropped from a script's `node:path` import where nothing else used it. `pr-size.mjs`, `procs.mjs` (which compares against its own `SELF`) and the research runs folder are not touched. `cli/test/main-module-symlink.test.mjs` starts each script directly, through a symlinked file and through a symlinked folder, with arguments that make it exit non-zero (npm-readme.mjs: `--check`), and expects the same exit status and text; a second test imports them all and expects no output.
- **Options considered:** one shared `main-module.mjs` next to each script (it needs a synced copy in nine script folders and the CLI, and every test that copies a script into a temp checkout on its own, such as `pr-rules-fakes.mjs` and the size evals, would also need the helper, so a script copied alone would fail to import); remove the guards (the scripts then run on every import); the guard written in each script, as above.
- **Why:** Many tests and installs copy a script without its neighbours, so a new import in each script is a new way for them to break. Eleven lines a script is cheaper than a helper that must ship to every folder a script lives in. The issue allows a helper but doesn't require one.

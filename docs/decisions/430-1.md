- **Decision:** `.gitattributes` marks each of the 51 copies in `sync-skills.mjs`'s `COPIES` list `linguist-generated`, one exact path per line, written by hand. `cli/test/copies-generated.test.mjs` imports `COPIES` (now exported; the script runs only when started, not when imported) and checks every copy with `pr-size.mjs`'s own `generated()`, against `.gitattributes` committed in a throwaway repo. A copy edited without its master still fails `sync-skills.mjs --check`, so hiding copies from the size count hides no new code. `.github/ISSUE_TEMPLATE/slice.md`, which `sync-skills.mjs` also copies but not through `COPIES`, is left as it is: it is outside the issue.

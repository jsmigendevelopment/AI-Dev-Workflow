# Decision 430-1

- **Date:** 2026-11-27
- **Decision:** `.gitattributes` marks each of the 51 copies `sync-skills.mjs` makes through its `COPIES` list `linguist-generated`, one exact path per line, written by hand. `COPIES` and the lists it is built from move unchanged into a data module, `scripts/sync-copies.mjs`, which `sync-skills.mjs` imports. `sync-skills.mjs` itself runs as it did before, with no main-module guard. `cli/test/copies-generated.test.mjs` imports `COPIES` from the data module and checks every copy with `pr-size.mjs`'s own `generated()`, against `.gitattributes` committed in a throwaway repo. It fails and names each copy without a line, and also fails if a master is marked, since a master's lines must count. None of the copies were marked before; the `.claude/skills/**` and `plugin/**` lines already covered those mirrors and stay as they are.
- **Options considered:** for the list: have `sync-skills.mjs` write the lines into `.gitattributes` (a second writer of a hand-edited file, and outside the issue's fence); folder globs such as `cli/src/preflight*.mjs` (shorter, but a glob can also catch a master or a new file that isn't a copy); one exact line per copy, checked by a test, as above. For the test's import: export `COPIES` from `sync-skills.mjs` behind a main-module guard (round 0; the guard compared `argv[1]` with the module's real path, so started through a symlinked file or folder the script did nothing and `--check` passed with a copy out of sync); a guard that compares real paths on both sides (still a guard that can drift); a data module with no guard, as above.
- **Why:** The issue allows either a generated list or one a test checks. Exact lines can't mark a master by mistake, and the test names any copy added to `COPIES` later. A copy edited without its master fails `sync-skills.mjs --check`, so hiding copies from the size count hides no new code; a test now runs `--check` through a symlinked file and a symlinked repo folder with one copy out of sync and expects exit 1. A data module needs no guard, so the script can't be skipped by how it is started. `.github/ISSUE_TEMPLATE/slice.md`, which `sync-skills.mjs` also copies but not through `COPIES`, is left as it is: it is outside the issue.

# Decision 425-1

- **Date:** 2026-11-28
- **Decision:** Every TanStack Start add-on's lint step, and the pack's pre-commit hook, make the Worker's types before `eslint --fix` (#425). This finishes what decision 320-1 did for the Sentry add-on.
  - **Add-ons:** the step in `analytics`, `database-supabase`, `email-resend`, `jobs`, `r2-uploads` and `stripe` was `pnpm exec eslint --fix . && pnpm format`. It is now Sentry's shape: `pnpm cf-typegen`, then `pnpm exec eslint --fix` and `pnpm exec prettier --write` on the files the add-on copies or edits, joined by `&&`. `cli/test/addon-lint-step.mjs` holds the checks from `sentry-scoped-lint.test.mjs`, which now uses it too with the same assertions; `addon-scoped-lint.test.mjs` runs them for the six, and fails when a new add-on runs ESLint without being listed.
  - **Pre-commit hook:** `lefthook.yml`'s lint job runs `pnpm cf-typegen && pnpm exec eslint --fix --no-warn-ignored {staged_files}`, the same order as `pnpm lint`. `lefthook-types.test.mjs` reads the line and runs it with a fake `pnpm`: ESLint starts only after the types file exists, and never when making it fails.
- **AI picks, not reviewed:**
  - **A folder the add-on brings whole may stand for its files** (`src/modules/billing`, `src/lib/email`), only when the pack has no such folder, so the step stays readable and still touches nothing else. Options: name every file (stripe's line would hold about 30 paths); allow the folder (picked); or take the list from `git diff --name-only` (needs a POSIX shell and a clean tree first, rejected in 320-1 too).
  - **A path with `$` is single-quoted** (`'src/routes/api/files.$id.ts'`), or the shell would expand `$id`. The test allows a quoted path only in that form.
  - **Generated files the pack's lint skips** (`src/routeTree.gen.ts`, listed in `.prettierignore`) don't count as touched, though `r2-uploads` and `stripe` name them. Running `eslint --fix` on an ignored file only prints a warning.
  - **`database-supabase` prose:** step 8 now backticks `README.md` and the two notes repository files whose comments it edits, so the step formats them. Step 3 says "setup-cloudflare" in place of the backticked path, because that file isn't edited.
  - **The hook makes the types on every commit that stages a script file,** not only when the file is missing. Options: always (picked: about a second, and types stay fresh after a `wrangler.jsonc` change); only when missing (`test -f ... ||`, faster, but stale types after a binding change misread the code the same way); a separate lefthook job (same cost, two places to read).
- **Checked by hand on a fresh app** (`init`, `add tanstack-start`, `git init`, `pnpm install`, `worker-configuration.d.ts` removed before each run):
  - **Hook:** with the old line, committing a one-line change to `src/server.ts` failed on two `no-unsafe-argument` errors. With the new line the same commit passed, and the types file existed after it.
  - **analytics:** after steps 1 to 5, the new step 6 changed only `src/routes/__root.tsx` (sorted the new import), `src/lib/security-headers.test.ts` and `src/components/web-analytics.test.ts`. `pnpm typecheck` passed, and `pnpm check` passed end to end (460 tests).
  - **email-resend:** the new step 7 changed only `src/server/composition.ts`, `src/server/email.resend.test.ts` and `src/lib/email/email.test.ts`, and `pnpm typecheck` passed. It stops on five ESLint errors in the add-on's own files, which the old whole-project step hit too, so they went to #487. The old step, on the same tree, also rewrote `scripts/connect/shell.ts`, `scripts/connect/terminal.ts` and `src/modules/notes/server/notes.http.test.ts`.
  - The other four need a network install or a migration, so they were checked by the tests only.
